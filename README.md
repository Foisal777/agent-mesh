# NextGen Predict

A polished sports-only prediction market demo built with Next.js and Tailwind. The experience includes a dark, high-end UI with market browsing, deposits, withdrawals, profile management, trade actions, and an admin control center.

## Features
- Landing page with promo banner, partners, and FAQ
- Market browsing and market detail trading flow
- Portfolio view with cancel/refund support
- Deposit and withdrawal flow with KYC enforcement
- Admin panel routes for markets, deposits, withdrawals, users, KYC, and settings
- Special admin route at /foisal

## Run locally
```bash
npm install
npm run dev
```

## Deploy to Netlify
1. Push this repository to GitHub.
2. Create a Netlify site from the repository.
3. Set the build command to `npm run build`.
4. Set the publish directory to `.next`.
5. Deploy.
